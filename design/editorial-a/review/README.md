## 夹具与验证边界

- 首页为隔离临时工程中的三件无图商品夹具，用于检查真实 ProductGrid/ProductCard 的列宽、占位图及长标题。它们没有写入正式 App 或业务服务。
- “我的”展示未注入真实账户时的原有占位状态。预览专用副本仅将初始 selectedTab 设为 1，用于进入该界面。
- 发布页通过预览专用 Navigation 打开；AI 及搜索使用初始空状态；登录使用实际 Index 页面。
- 隔离工程位于系统临时目录并保留，未执行批量删除。正式工程中没有添加任何 Review 页面或夹具路由。
- 正式 HAP 只包含产品源码与资源，不应包含本目录的截图、日志或预览夹具。
- 已检查的只是上述页面的静态布局。大字号、输入法、系统弹层、相册和拍照，以及注册、交易、聊天、AI 的真实联网交互仍待模拟器／真机验收。
- 未对尚未捕获截图的商品详情、交易详情、注册表单展开状态作视觉验收声明；它们已通过正式 ArkTS 构建和本次 UI 静态契约检查。

业务层另有 32 项现有前端逻辑回归通过；该结果与视觉检查分别记录，不把截图作为交易逻辑验证依据。
