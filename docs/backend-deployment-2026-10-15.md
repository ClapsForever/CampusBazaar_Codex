当前 Mac 分别使用正常域名解析，以及固定服务器 IP 并保留域名证书校验尝试访问公网 HTTPS；两次均在 TLS 握手阶段报 `SSL_ERROR_SYSCALL`，没有取得 HTTP 响应。服务器端 HTTPS 校验通过，但本次尚未验证当前 Mac 网络的外部访问；没有为此扩大原白名单或改动网络配置。

Agent 重启会清空内存中的续聊上下文。App 中点击“新对话”后继续使用，SQLite 中保存的历史记录仍可回看。平时通过 licx 的用户服务管理自己的两个后端：

```bash
systemctl --user status campusbazaar-licx-api.service campusbazaar-licx-agent.service --no-pager
```
