# Agent 问法兼容修复与验收（2026-10-12）

已修复改写评测中发现的预算丢失、取消条件失效、翻页重复、成色漏召回和版本关键词组合问题，并补齐价格排序、最便宜一件、排除关键词、有限用途找物和商品名称指代。修复已部署到 licx 的独立实例。

## 实际行为

- “五十块”“50块钱”“under 50 yuan”与“50元以内”应用相同预算。金额单独解析和校验，切换商品不再因类别解析遗漏而删除用户明确保留的预算。
- “不看价格了”“多少钱都行”“价格上限去掉”“新旧都可以”“哪个校区都行”可以取消对应限制；否定取消不会解除约束，未提及的条件继续保留。
- 有已知上限时，“再便宜20元”“再下调20块预算”按上限减去指定金额；没有上限时会询问新的最高金额，避免猜测。
- “江湾”规范为“江湾校区”；区分校区要求和偏好，“最好在江湾”不会被错误执行为硬筛选。条件与校区的作用范围按原文分句校验。
- “没用过”应用全新条件；九成新以上包含九成新及全新。真实 API 和模拟客户端使用同一最低成色语义，明确的七／八／九／十成新由服务端校验。
- “同济第七版高数教材”拆成学科关键词与版本。“继续”“还有其他的吗”“第二页”实际读取下一页，按模型计划及明确页码执行，不再重复第一页。
- 价格升降序和“最便宜的一件”由业务 API 对全部匹配商品排序后分页；不只是对当前页或回复文字排序。
- 排除关键词在后端查询中执行；名称指代依据本轮实际展示的标题与顺序，详情与比较仍重新检查商品可见性。规划阶段只提供标题，不提供商品描述中的指令。
- 表述模型收到本轮问题及本轮实际结果，便于回答指定属性；交易、支付、身份和学校权限约束保持原有范围。

用途映射目前支持本轮明确实现的照明与校园骑行通勤等少量常见关系；排除条件是关键词匹配。模型仍需处理其余自然语言，下面的通过率仅描述这套问法集。
