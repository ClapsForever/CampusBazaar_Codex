- [隐私政策](privacy-policy.md)：按功能列明数据、用途、可见范围、系统选择器、图片签名、AI 外发、存储和现有缺口。

这些文件仍为内部测试草案。2026-10-23 后端已加入强制邮箱验证码注册与阿里云发信适配，App 验证码界面、真实云端配置和投递尚未验收；旧账号不补造邮箱验证时间。邮件、账号恢复、运营主体、联系渠道、权益/注销/删除/留存及第三方实际条款仍需按事实补齐。不得将草案接受记录视为正式公开运营条件已满足。

App 内展示副本时应保留版本、草案提示、待补事项和必要说明，并与这些源文件同步。用户协议与隐私政策版本和服务端登记值保持一致；正文变更影响用户接受范围时应更换版本并按适用规则重新告知，不应覆盖旧版后仍以旧版本号留痕。社区规则可独立阅读，不应在未披露的情况下追加注册必勾条件。
