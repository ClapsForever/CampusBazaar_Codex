# 校园集市法律文档草案

统一版本：`2026-10-18-draft-2`；拟稿日期：2026-10-18。

- [用户协议](user-agreement.md)：账号、现有服务、交易状态、AI、内容权利及责任。
- [隐私政策](privacy-policy.md)：按功能列明数据、用途、可见范围、系统选择器、图片签名、AI 外发、存储和现有缺口。
- [社区与交易规则](community-rules.md)：发布、禁售、沟通、线下交易、状态操作和拟定治理流程。
- [发布前边界确认清单](launch-checklist.md)：负责人待补事实、未实现能力、代码核对线索和已查阅的官方法律来源。

这些文件是基于当前实现完成的内部测试草案，已经确认任意邮箱测试、不验证邮箱归属；当前注册采用邮箱、密码、确认密码和主动同意协议，成功后自动登录，图形验证码已暂时停用并列入发布前待办；运营主体、联系渠道、权益/注销/删除/留存及第三方实际条款尚未确定。不要把待办内容改写为已有能力，或者将“已接受草案”视为可以直接正式运营。

App 内展示副本时应保留版本、草案提示、待补事项和必要说明，并与这些源文件同步。用户协议与隐私政策版本和服务端登记值保持一致；正文变更影响用户接受范围时应更换版本并按适用规则重新告知，不应覆盖旧版后仍以旧版本号留痕。社区规则可独立阅读，不应在未披露的情况下追加注册必勾条件。
