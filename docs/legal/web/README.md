## 当前没有准备托管地址时

先完成标题和正文审阅，不以本地文件路径代替公网URL。可以把定稿后的HTML放到已有的上海服务器，通过现有Nginx提供一个独立的静态页面，无需建设完整官网，也不需要让用户登录后才能阅读。

建议页面路径为 `/legal/user-agreement.html`。如果之后使用某个已配置HTTPS的域名，该域名与这个路径组合，才构成可填写的真实协议链接。历史资料中的 `api.campusbazaar.cn` 只证明曾经使用过该域名，不代表本文件已经在那里上线。

以下是现有Nginx站点可采用的**配置示例**，需由部署负责人核对实际目录和站点后加入已有HTTPS的 `server` 块。它不是已经执行的配置：

```nginx
location = /legal/user-agreement.html {
    alias /var/www/tongchuangji/legal/user-agreement.html;
    default_type text/html;
    charset utf-8;
    add_header X-Content-Type-Options nosniff always;
}
```

将HTML上传到示例中的确切路径，或把 `alias` 改成实际上传文件的完整路径。该精确路径由Nginx直接提供，不需要调整业务API的鉴权路由。站点证书、域名解析、部署权限及适用的备案等事项，应按真实现有环境处理。

实际部署完成后，在未登录状态打开URL，确认看到完整《同窗集用户协议》正文且手机可阅读，再把该URL复制到华为的“协议链接”。本次没有创建公开网址或替用户提交控制台。

## 定稿前仍需处理

1. 补充实际联系地址及生效日期，确认服务范围和身份/年龄准入安排。
2. 落实邮箱注册、账号/个人信息申请、举报申诉、数据保留、安全传输、AI说明及标识等正文已经指出的产品与运营缺口。原发布差距审查可继续用于核对。
3. 隐私政策和社区与交易规则仍按独立文件管理。本用户协议没有自动合并或替换它们，也没有生成未存在的公开链接。
4. 定稿后移除网页和正文中对应的审阅稿提示，使用正式版本号，保存本次正文快照；不能仅移除提示就视为缺口已解决。
5. 同步最终App名称、展示正文、协议接受版本及适用的旧用户告知流程。2026-10-30 已按用户要求将 App 显示名称、三份离线协议及本网页中的产品名称统一为“同窗集”；此次仅替换品牌文案，条款内容与注册协议版本标识保持不变，其余定稿事项仍待处理。
