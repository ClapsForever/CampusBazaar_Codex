# 校园集市：个人设置与 AI 对话历史

本次修改位于 `CampusBazaar_Codex`。桌面应用标签、启动能力标签、登录页和首页名称统一为“校园集市”。

## AI 找物

- “新对话”旁新增“历史记录”，每轮成功回复由业务 API 自动写入 SQLite，无需用户手动保存。
- 列表按对话开始时间倒序排列，显示首个问题、日期时间及对话轮数，可加载更多。进入详情按发送顺序查看问题、回复和推荐商品入口。
- 历史仅供回看；“返回对话”恢复当前对话及未发送草稿，“新对话”开始独立搜索。历史读取不覆盖当前会话。
- 历史归属由登录令牌确定，不能读取或使用其他账号的会话。退出登录清空前端状态，后端记录保留。
- API、Agent 或 App 重启不会删除已保存历史。Agent 的续聊上下文仍在内存，重启或过期后请点击“新对话”。更新前未保存且已丢失的对话无法恢复，失败的 AI 请求不会成为成功轮次。

## 个人设置

- 入口：“我的 → 个人设置”。选择一张相册图片，预览头像并编辑昵称，点击“保存个人资料”。支持 JPEG、PNG、WebP，最大 5 MB；昵称 1–24 个字符。
- 保存后同步“我的”资料，重新登录、重启 API 后仍保留。昵称和头像也用于卖家资料及交易对方资料。
- 首次设置密码验证 6 位测试验证码（业务 API 配置的 `DEV_LOGIN_CODE`）；已有密码时输入当前密码、新密码及确认密码。
- 密码为 8–64 位，至少包含一个字母和一个数字，以随机盐 scrypt 摘要存储。保存后清空输入，保留当前登录，撤销其他登录会话。
- 登录页可切换验证码与密码登录。首次登录继续使用验证码；设置密码后可使用手机号和密码登录。切换方式会清空已输入凭据。
