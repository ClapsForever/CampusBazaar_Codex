## 已整理的代码

- 移除无入口的旧版买家首页路由和导入。当前首页仍使用 `HomeView` 和共享的 `BuyerHomeViewModel`；后者必须保留。

- 移除 Agent 代理函数的无用参数，标明 Mock 偏好查询未使用的身份参数。
- 移除测试脚本中已失效的源码替换逻辑；两个 UI 回归脚本默认复用 `backend/api` 安装的 TypeScript，不再需要配置 DevEco 内部路径。`ARK_TYPESCRIPT` 仍可用于指定编译器。

- 补充忽略 `oh_modules`、`local.properties`、`.vscode` 和 CSR 文件，避免提交依赖、本机 SDK 配置及生成文件。

## 修复的问题

- 交易列表的旧响应、切页后的消息发送/卖家操作、切换账号后的响应不再覆盖当前状态；静默刷新失败保留已有列表，重试清除错误。
- 发送中继续编辑的下一条草稿不会被清空；旧聊天读取不会覆盖新消息；慢轮询不重叠，旧轮询不会把刚接受的交易回退为待确认。
- 邮箱登录使用请求版本校验；退出立即清空本机身份，延迟的旧登录或旧退出响应不会恢复旧账号或清除新登录。
- Agent 请求编号同时校验问题与原始会话；冲突返回 409，相同首轮请求并发只执行一次，失败可重试。
- Agent 在后续请求中定期回收过期会话和响应缓存，保留处理中的会话；已取消的业务读取不再发起 HTTP 请求。
- API 的无效 URL 百分号编码返回 400，避免误报为服务器内部错误。
