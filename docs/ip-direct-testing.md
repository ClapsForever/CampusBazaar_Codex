# 小组模拟器接入：阿里云公网 IP

当前测试入口为 **`http://47.117.96.16:18080`**，使用邮箱密码登录，也可自助注册。原预置账号、商品、图片、交易、聊天和 AI 历史均已迁入，账号密码继续使用。API 与 App 的图片基址一致。

这是小组开发测试入口，HTTP 会明文传输密码和登录令牌，请使用测试账号；正式发布前恢复 HTTPS。迁移、验证与备份见[2026-10-20 阿里云部署记录](aliyun-migration-2026-10-20.md)。

## 每位组员的操作

1. 在项目仓库运行 `git pull`。
2. 确认 `entry/src/main/ets/service/BackendRuntimeConfig.ets` 中的 `BUSINESS_API_BASE_URL` 为 `http://47.117.96.16:18080`。
3. 在电脑或模拟器浏览器打开 `http://47.117.96.16:18080/health/ready`，应返回 `{"status":"ok"}`。
4. 在 DevEco Studio 重新构建、签名并运行 App，使用原有邮箱密码，或通过启动页注册入口创建测试账号。
5. AI 找货先点“新对话”。已保存的历史可以回看，迁移前内存中的续聊上下文不会恢复。

腾讯云旧入口 `http://101.35.53.59:18080` 临时转发到同一个阿里云后端，旧安装包暂可继续使用；为摆脱旧服务器依赖，仍请安装指向阿里云的新包。旧库不再写入，两个地址不会形成两套独立账号或数据。

## 当前服务器配置

- 阿里云 licx 独立 Nginx 监听公网 18080；业务 API 和 Agent 只监听回环 18081、3300。
- 安全组 TCP 18080 已由用户配置；入口不配置逐人 IP 白名单，业务接口仍有会话鉴权、资源归属检查和限流。
- 登录与注册限流、内部接口屏蔽、签名图片、AI 并发限制保留。图形验证码接口暂不开放。
- 三个用户服务均已自启，`Linger=yes`，退出 SSH 不影响运行。
- 实际配置见 [`deploy/aliyun/licx-ip-test`](../deploy/aliyun/licx-ip-test/)。腾讯云队友在 80 端口的另一套实例未参与迁移。

## 连接排查

- 连接超时：核对阿里云 TCP 18080 入站规则和当前网络代理。Windows 可执行 `curl.exe --noproxy "*" --max-time 15 http://47.117.96.16:18080/health/ready`。
- 健康检查正常但 App 连接失败：确认重新安装了新地址的 App，并检查模拟器网络。根路径不是登录网页，不能凭根路径的返回判断登录是否正常。
- 登录 401：请求已经到 API，核对邮箱密码。队友实例的账号和旧验证码不能用于本实例。
- 匿名资料接口 401、内部路径 404、空注册请求 400 `INVALID_EMAIL` 均属于预期。业务操作的 403 需结合资源归属和角色权限判断。
- 图片打不开：确认 API 的 `PUBLIC_BASE_URL` 与 App 均为阿里云地址。签名链接有有效期，重新打开列表获取新链接。
