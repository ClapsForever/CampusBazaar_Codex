## 连接排查

- 请求超时：先核对腾讯云 18080 入站规则和本机代理设置。电脑可用 `curl --noproxy '*' --max-time 15 http://101.35.53.59:18080/health/ready`；Windows 用 `curl.exe --noproxy "*" --max-time 15 http://101.35.53.59:18080/health/ready`。
- HTTP 403：检查实际请求的公网出口是否仍在 Nginx 白名单内；浏览器与模拟器可能使用不同的代理出口。不要通过修改成队友的 80 端口来测试本实例账号。
- 健康检查成功、App 仍提示连接失败：确认重新安装的是本仓库的新包，地址包含 18080，再检查模拟器网络。
- 登录返回 401 或邮箱密码错误：连接已到业务 API，核对本实例的预置账号。队友后端的账号和旧验证码不能直接用于本实例。
- 未登录访问业务资料返回 401、访问 `/internal/` 返回 404 属于预期；入口不是登录网页，不要用根路径判断登录是否成功。
