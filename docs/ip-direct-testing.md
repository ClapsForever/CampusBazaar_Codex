1. 获取包含本次客户端修改的代码；不能假定 `main` 已包含当前工作区的修改。

## 连接排查

- 连接超时：核对域名解析、HTTPS 443 入口及设备网络。Windows 可执行 `curl.exe --noproxy "*" --max-time 15 https://api.campus-bazzar.work/health/ready`。
- 健康检查正常但 App 连接失败：确认重新安装了新地址的 App，并检查模拟器网络。根路径不是登录网页，不能凭根路径的返回判断登录是否正常。
- 登录 401：请求已经到 API，核对邮箱密码。队友实例的账号和旧验证码不能用于本实例。
- 匿名资料接口 401、内部路径 404、空注册请求 400 `INVALID_EMAIL` 均属于预期。业务操作的 403 需结合资源归属和角色权限判断。
- 发码 429：按服务端倒计时等待；503 表示邮件服务暂不可用，不连续自动重试。验证码无效时检查邮箱、最新验证码及有效期。
- 图片打不开：确认 API 的 `PUBLIC_BASE_URL` 与 App 均为正式 HTTPS 域名。签名链接有有效期，重新打开列表获取新链接。
